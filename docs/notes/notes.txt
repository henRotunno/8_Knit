View Reflections:

HttpResponse vs render:
HttpResponse is useful for returning simple content directly, while render() is more convenient when displaying data through reusable HTML templates.

Base CBV vs Generic CBV:
Base CBVs give us more control over request handling, while Generic CBVs reduce repeated code for common tasks such as displaying lists of model objects.
