View Reflections:

HttpResponse vs render:
HttpResponse is useful for returning simple content directly, while render() is more convenient when displaying data through reusable HTML templates.

Base CBV vs Generic CBV:
Base CBVs give us more control over request handling, while Generic CBVs reduce repeated code for common tasks such as displaying lists of model objects.

Section 6: Creating APIs
We created an API endpoint using Django JsonResponse to serve activity data from the Activities model. The endpoint supports filtering through the q query parameter using activity_name__icontains.
The API serves each activity's activity_id and activity_name. We also added a standard HttpResponse endpoint to compare the response type with JsonResponse.

Part 1: Internal API & Vega-Lite Charts

Created two database-backed internal JSON endpoints for Vega-Lite visualizations.

1) /api/chart/activity-categories/
   - Aggregates Activities by category using Count().
   - Used as the data source for the Activities by Category bar chart.

2) /api/chart/user-friends/
   - Returns each user's ID, username, and friend count.
   - Used as the data source for the Friend Count by User scatter chart.

Both Vega-Lite specifications load data through API URLs rather than inline data.
The charts are embedded on /vega-lite/ and chart outputs are also available through:
- /vega-lite/chart1.png
- /vega-lite/chart2.png
